## 1. 해석 순서 (고정 · 변경 금지)

모든 명리 기반 콘텐츠는 **아래 8단을 이 순서대로** 거친다. 단계를 건너뛰거나 순서를 바꾸지 않는다.

| # | 단계 | 내용 | 금지 |
|---|------|------|------|
| 1 | **팩트** | 월령·일간·십성·격국·용신·합충·대운·세운·일진 — **계산·입력값만** | AI 추측·없는 별 창작 |
| 2 | **환경** | 이 시기·오늘의 **공기·압력·리듬** (온도·속도) | 성격 라벨 |
| 3 | **반응** | 일간 = 그 환경에 대한 **몸의 자세·반복 반응** | 「~한 사람」 |
| 4 | **5축 장면** | 관계 · 일 · 돈 · 선택 · 감정 — **구체 장면** | 추상 진단 |
| 5 | **흔들릴 때** | 스트레스·실수가 나는 **순간·장면** | 조심하세요·훈계 |
| 6 | **비서 제안** | 실행 가능한 **구조·행동** (§1-A) | 명언·교훈·「더 강해지세요」 |
| 7 | **한 문장** | 패턴 인식 클로징 (§3 준수) | 원래 ~한 사람 |
| 8 | **근거** | 십성·월령·격국 — **접이·전문가 모드** | 본문 용어 나열만 |

### 1-1. 사주 해석 우선순위 (고정)

사주·프리미엄·원국 번역에서 명리 요소를 쓸 때:

```
월령 → 일간 → 십성
```

| 규칙 | 설명 |
|------|------|
| **월령** | 환경(§1 단계 2)의 **1순위** — 계절·온도·압력 |
| **일간** | 반응(§1 단계 3) — 환경에 대한 자세 |
| **십성** | 5축 장면(§1 단계 4)의 재료 — **본문 전면 1~2개만** |
| **금지** | 십성 하나로 **인격·성격 전체 단정** |
| **나머지 십성** | 근거 접이(§1 단계 8)에만 |

오늘의 운세는 **일진 + 원국**이 환경·반응 단계를 대체할 수 있다. 다만 원국이 있으면 월령·일간 팩트는 접이 근거에 반드시 남긴다.

### 1-A. 비서 제안 (개입)

| 금지 | 허용 |
|------|------|
| 침착하세요 · 신중하세요 · 조심하세요 | 피드백 4단(문제·영향·기대·점검 시점) |
| 더 강해지세요 · 긍정적으로 | 결정 시한 · 프리모텀 1장 |
| 명언 · 교훈 | 가격·보상 **객관 지표** |
| | 경계·역할 구분 · 위임·품질지표 3~5개 |

- **오늘:** 비서 제안 **1개** (§4)  
- **사주·프리미엄:** 비서 제안 **3~5개** — 각각 근거 1줄

## 2. 장면 우선 원칙

**추상어 단독 사용 금지.** 반드시 **인간이 떠올리는 장면**으로 쓴다.

| ❌ 추상 | ⭕ 장면 |
|--------|--------|
| 책임감이 강하다 | 부탁을 거절하고도 마음에 남는다 |
| 신중하다 | 회의가 끝난 뒤 혼자 다시 검토한다 |
| 표현력이 좋다 | 생각만 할 때보다 말하거나 쓰기 시작할 때 길이 열린다 |

## 3. 문체 — 금지 · 허용

### 3-1. 금지 문체 (절대)

다음은 **본문·카드·채팅·API 응답·랜딩** 어디에도 쓰지 않는다.

| 유형 | 예시 |
|------|------|
| **강/약** | 강하다 · 약하다 · ~이 강합니다 · 부족하면 ~약해 |
| **추상 진단** | 리더십 · 창의력 · 표현력 · 책임감(형용사만) · 완벽주의적 |
| **낙인** | 당신은 **원래** ~한 사람입니다 / ~한 성격입니다 |
| **교훈·명령** | 조심하세요 · 신중하세요 · 침착하세요 · ~하세요(훈계) |
| **예언** | 연락이 온다 · 좋은 일 · 재물이 들어온다 · ~월에 운이 좋다 |
| **라벨** | MBTI식 유형 · 리더형 · 분석형 · ~타입 |
| **사주 설명 중심** | 식신은 표현의 별입니다 (용어 강의) |
| **본질주의** | 여성이라서 ~ · 남성이라서 ~ |

**v2.1과의 차이:** v2.1은 「당신은 ~」를 전면 금지했다. v3는 **§3-2**의 조건부 패턴 서술만 허용한다.

### 3-2. 허용 문체

| 패턴 | 용도 |
|------|------|
| 이 시기에는 **~가 반복되기 쉽습니다** | 환경·흐름 (예언 아님) |
| 관계에서는 **~가 나타날 수 있습니다** | 5축 — 관계 |
| 결정 직전 **~를 한 번 더 확인하려는 흐름**이 있습니다 | 5축 — 선택·일 |
| **~하는 편입니다** / **~쪽으로 움직이기 쉽습니다** | §3-3 조건 충족 시만 |
| 따옴표 **장면** | 「이 정도면 되겠지」가 나올 때 |
| **(근거: 월령 인월 · 식신)** | 접이 또는 전문가 모드 |

### 3-3. 「~하는 편입니다」 사용 조건

아래 **둘 중 하나**를 만족할 때만 허용한다.

1. 직전 문단에 **5축 장면**이 이미 있음  
2. 같은 블록에 **`(근거: …)`** 가 붙음  

**금지 예:** 장면 없이 「당신은 리더십이 있는 편입니다」

**허용 예 (§2 장면 후):**

> 회의가 끝난 뒤 혼자 다시 검토하는 편이에요.  
> *(근거: 정관)*

### 3-4. 사주 본문 허용 예

> 생각만 할 때보다 말하거나 쓰기 시작할 때 길이 보이는 편이에요.  
> 혼자 고민할수록 답답해지고, 표현을 시작하면 방향이 보이는 경우가 많아요.  
> *(근거: 식신)*

## 5. 다섯 축

사람의 고민은 아래 **5축** 안에서만 표현한다. §1 단계 4(5축 장면)와 1:1로 연결한다.

| 축 | 예시 |
|----|------|
| **관계** | 연락, 거리, 말투, 기대, 경계 |
| **일** | 미룸, 협업, 마감, 위임, 품질 |
| **돈** | 지출, 가격, 현금흐름, 보상 |
| **선택** | 예/아니오, 타이밍, 확장 |
| **감정** | 불안, 후회, 폭발, 잠수 |

**십성 장면 사전:** 전면 십성 1~2개마다 5축 + 흔들릴 때 장면을 데이터로 둔다 (구현: `sipsin-scene-dictionary` 예정).

다음 **역할**에서 생기는 패턴으로만 쓴다. 성별이 아니라 **역할·맥락**이 기준이다.

|------|-----------|
| **대표** | 대외 메시지·브랜드·결정 공개 |

## 8. 인식론·면책

- 명리·사주 해석은 **자기이해·상담 참고용 해석 프레임**이다.

## 9. 검수 체크리스트

문장·카드·API 필드·프롬프트 출력 **하나마다** 아래를 모두 통과해야 한다.

| # | 질문 | 통과 기준 |
|---|------|-----------|
| 1 | **원국 팩트**가 있는가? | 없는 월령·십성·합충을 지어내지 않았는가 |
| 2 | **월령/환경**이 먼저 반영되었는가? | 사주에서 환경 전에 성격·십성 단정이 나오지 않았는가 |
| 3 | **낙인·교훈·예언**이 아닌가? | §3-1 금지 목록 0건 |
| 4 | **5축** 중 하나에 연결되는가? | 관계·일·돈·선택·감정 중 최소 1축 |
| 5 | **실제 장면**이 있는가? | 추상 형용사만으로 끝나지 않았는가 |
| 6 | **구조적 행동 제안**이 있는가? | (비서 구간) 훈계·명언이 아닌 실행·구조인가 |
| 7 | **「이거 내 이야기인데?」**를 느낄 수 있는가? | 맞추기·운세가 아니라 **내 반복**으로 읽히는가 |

**보조 (제품별):**

- 오늘: §4 **어느 칸**인가?  
- 사주: §1 **어느 단계**인가? 십성 전면 **2개 이하**인가?  
- 행운: §6 **값+의미**인가?  
- 페르소나: §7 **역할·구조**인가, 본질주의가 아닌가?
