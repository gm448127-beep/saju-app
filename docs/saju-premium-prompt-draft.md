> **방향:** [saju-report-direction.md](./saju-report-direction.md) · [content-constitution-2.1.md](./content-constitution-2.1.md)

## 제품 3단계

| 단계 | 이름 | 역할 |
|------|------|------|
| 무료 | 오늘의 나 발견 | 헌법 4단 — 오늘 흐름·타이밍·실수·비서 제안 |
| 유료 | 나를 이해하는 리포트 | 패턴·분야별 — 원국 근거 + 인간 언어 |
| **프리미엄** | **평생 소장용 인생 설명서** | 원국 전체 번역 — 이 문서·프롬프트 대상 |

---

## 해석 파이프라인 (모든 문단)

```
원국 분석 → 인간 언어 번역 → 실제 삶의 장면 → 비서의 제안
```

### 예시

❌ 식상이 강하여 표현력이 좋습니다.

⭕ 생각만 할 때보다 말하거나 쓰기 시작할 때 길이 보이는 사람입니다.  
혼자 고민할수록 답답해지고, 표현하기 시작하면 방향이 보이는 경우가 많습니다.  
(근거: 식상 강함 — 원국 십신 개수 기준)

---

## 원칙

1. **모든 문장은 원국 기반** — 십신·오행·격국·용신·합충형파해·대운·세운. AI 추측 금지.
2. **사주를 설명하지 말고 사람을 설명** — 반복 패턴, 장면, 선택.
3. **교훈·낙인·예언 금지** — v2.1 동일.
4. **검증** — 전문가 「근거 있다」 + 사용자 「공감」 **둘 다**.

---

## 프리미엄 리포트 섹션 (출력 순서)

1. **이 설명서를 읽는 법** — 번역물이라는 안내  
2. **한눈에 보는 나** — 핵심 1문단 + (근거)  
3. **반복되는 나의 패턴** — 3패턴 × (본문·장면·근거)  
4. **관계에서** — 장면 + 비서 제안 + 근거  
5. **일과 돈에서** — 장면 + 비서 제안 + 근거  
6. **선택과 감정에서** — 장면 + 비서 제안 + 근거  
7. **지금 이 시기** — 대운·세운 + 장면 + 근거  
8. **운명비서의 제안 다섯 가지** — 구체 행동 5개 + 근거  
9. **전문가가 본 원국** — 용어·수치 요약 (본문과 일치)  
10. **마무리** — 예언·위로 없이

- `summary`·`personality` → **복사 금지**, 키워드만 참고
