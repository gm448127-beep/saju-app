## 1. 재정비가 필요한 이유

현행 v2.1은 **오늘의 운세 4단**·**5축**·**장면·교훈 금지**를 잘 잡았으나, 사주·프리미엄·명리 엔진 쪽에는 다음이 **문서·데이터·프롬프트로 고정되지 않았다.**

| 공백 | 조사 자료가 말하는 것 |
|------|------------------------|
| 해석 순서 | **월령(환경 압력) → 일간(반응 방식) → 십성 장면** |
| 데이터 단위 | **일간×12월령** 앵커, **십성×5축** 장면 사전 |
| 문체 규칙 | 「당신은 ~한 사람」의 **허용·금지 경계**가 v2.1과 사주 방향 문서에서 다름 |
| 세그먼트 | 여성 경영·전문직 **구조적 패턴** (본질주의 금지) — 제품 레이어 미정 |
| 인식론 | 명리 = **해석 프레임** ⭕ / 과학·결정론·사건 예언 ❌ |

이번 재정비는 **리브랜딩이 아니라 번역 규칙의 통합**이다. 아이보리·5축·「나 얘기」 목표는 유지한다.

## 2. 세 자료가 공통으로 말하는 「운명비서 위치」

```
전통 명리 (용어·원국)
        ↓
운명비서  ← 환경·선택·장면으로 번역 (여기)
        ↓
AI 심리테스트 / 성격 유형 / 본질주의 라벨
```

| 원칙 | 1 월령 | 2 여성 리더 | 3 십성 |
|------|--------|-------------|--------|
| 본문 | 계절·압력·리듬 | 구조·역할·평가 압력 | 회의·연애·통장에서 보이는 행동 |
| 금지 | 강/약, 용어 나열 | 「여성이라서~」, 더 강해져라 | 성격 형용사, 단일 별로 전체 단정 |
| 5축 | 관계·일·돈·선택·감정 | 동일 매핑 | 각 십성마다 5장면 + 흔들릴 때 |
| 개입 | 비서 제안 1개 | 기준 문서화·경계·가격 스크립트 | 구조·행동 (훈계 아님) |
| 근거 | 월령·일간·십신 (접이/각주) | 연구·장면 (합성) | 원전 생활어 + 명식 팩트 |

**한 줄 정의 (v3 제안):**  
운명비서는 사주·일진·월령을 **「왜 오늘 이렇게 선택하게 되는지」**를 **관계·일·돈·선택·감정의 장면**으로 번역하는 서비스다. 미래 사건을 맞히거나 성격을 찍어 주지 않는다.

## 3. 명리 번역 파이프라인 (통합안)

조사 1·3번과 사주 방향 문서를 합치면 **모든 생성·규칙 엔진**이 아래 순서를 따르는 것이 맞다.

```
[1] 팩트 시트 — 월령, 일간, 십성 개수·위치, 격국·용신·합충·대운·세운 (AI 추측 금지)
[2] 환경 문장 — 이 월령/오늘의 공기·압력 1문장 (온도·속도·사회적 압력)
[3] 반응 문장 — 일간이 그 환경에서 취하는 자세 (라벨 아님)
[4] 5축 장면 — 관계 · 일 · 돈 · 선택 · 감정 (각 1~2문장, 따옴표 장면 허용)
[5] 흔들릴 때 — 실수·스트레스 장면 (교훈·주의 아님)
[6] 비서 제안 — 오늘/이 시기 실행 가능한 구조·행동 1개 (또는 사주: 3~5개)
[7] 운명비서 한 문장 — 패턴 인식용 클로징 (낙인·예언 아님)
[8] 전문가 접이 — 십성·월령·격국 근거 (본문과 1:1)
```

### 오늘의 운세 vs 사주

| 제품 | 구조 | 파이프라인 |
|------|------|------------|
| 오늘 (무료) | **4단 고정** (흐름·타이밍·실수·제안) | 일진+사주 팩트 → 4단에 매핑 |
| 사주 (무료·유료) | 섹션 가변 (패턴·관계·일·돈·시기…) | 동일 5축 + 월령 우선 |
| 프리미엄 | 10섹션 (기존 초안) | 동일 + 「전문가가 본 원국」 |

**월령:** 오늘은 **일진·월령 교차**로 암시, 사주·프리미엄은 **월령을 1순위**로 명시.

**십성:** 한 사람에게 여러 십성이 동시 작동 — **전면에 든 별 1~2개**로 장면을 쓰고, 나머지는 근거 접이에만 (조사 3번).

## 4. 「당신은 ~」 문체 — 재정비안

v2.1 §2는 **성격 낙인**을 금지한다. 조사 1번·사주 방향·프리미엄 예시는 **「당신은 ~하는 사람입니다」** 클로징을 쓴다.

| 구분 | 예 | 판정 |
|------|-----|------|
| **낙인 (금지)** | 당신은 원래 이런 사람 / 행동력 좋은 사람 / 리더십 있다 | MBTI·칭찬·빈 일반화 |
| **패턴 서술 (허용)** | 당신은 시작 버튼을 눌러야 숨이 트이는 **쪽으로 움직이기 쉽습니다** | 원국 근거 + 장면 뒤 1문장 |
| **오늘 한정 (허용)** | 오늘은 이런 흐름이 나타나기 쉽습니다 | v2.1 유지 |
| **구조 제안 (허용)** | 피드백은 감정 전에 「문제-영향-기대-점검」 4단으로 | 조사 2번 개입 |

**v3 규칙 제안:**  
- **「당신은 ~한 사람입니다」** 단독 문장 금지.  
- **「당신은 ~할 때 / ~하는 편입니다 / ~쪽으로 움직이기 쉽습니다」** + 직전 장면 또는 `(근거: …)` 있으면 허용.  
- 클로징 **「운명비서 한 문장」**은 필수이되, 위 패턴 서술 형식만 사용.

## 5. 여성 경영·전문직 레이어 (선택)

조사 2번은 **성별 본질론이 아니라 구조·역할·평가 압력**의 합성 장면이다.

| 반복 패턴 | 5축 | 운명비서 대응 |
|-----------|-----|----------------|
| 피드백 지연 후 폭발 | 일·관계 | 실수 장면 + 「4단 피드백」 제안 |
| 증거 축적형 결정 | 선택·일 | 타이밍·선택 장면 + 결정 시한 제안 |
| 돈=완충재, 가격 인승 주저 | 돈 | 돈 장면 + 가격·보상 스크립트 제안 |
| 확장=정체성 공포 | 선택·일 | 흐름 + 위임·품질지표 제안 |
| 정서노동 과잉 | 관계·감정 | 실수 장면 + 역할 구분 제안 |
| 재혼=시간·자녀·경계 | 관계·선택 | 관계 장면 (사랑 예언 없음) |

**제품 적용:**  
- 전 사용자 헌법에 넣지 않음.  
- **페르소나 팩** (`docs/persona-female-founder.md` 등) 또는 프롬프트 **선택 모듈**로만 — 명식·십성·월령 팩트와 **교차**할 때만 사용.

**금지:** 「여성 CEO라서~」, 관계지향적 여성, 더 강해지세요.

## 7. 인식론·면책 (v3에 신설 권장)

조사 1·3번이 공통으로 밝힌다.

- 명리 해석은 **상담·자기이해용 해석학적 프레임**으로 쓸 수 있다.  
- **과학적으로 검증된 운명 모델·성격 결정론**으로 제시하지 않는다.  
- 단일 십성·단일 월령으로 **전체 인격을 고정**하지 않는다.

앱 카피·푸터·리포트 말미에 **1~2문장** 수준으로 통일 (재미·참고, 중요한 결정은 전문가 상담 — v1.0 계승).
